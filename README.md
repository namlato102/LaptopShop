# Laptop Shop
This is a simple e-commerce website for selling laptops. It is built using Spring Boot and MySQL.

## Environment Variables

To run this project, you will need to create .env file and add the following environment variables from .env.example to your .env file

## Tech Stack

**Frontend:**
- HTML, CSS and Javascript
- View Engine: JSP
- AJAX to call APIs

**Backend: (Java)** 
- Spring Boot 
- Spring MVC 
- Spring Security
- Spring Data (Hibernate/JPA)
- Build tool: Maven

**Database:**
- MySQL
